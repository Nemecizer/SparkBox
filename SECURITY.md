# Security and operation

SparkBox can perform privileged operations on the nodes you configure. Review the proposed action and selected nodes before authorizing it. Start with the browser Demo and read the built-in Help.

Admin, Touch ID or Mac-password confirmation, Look only, SSH host identity, ownership/leases, protected package plans and debug write fences remain active. Never bypass them to work around a refused operation. Unknown or changed identity must be reviewed on the actual device.

Credentials belong in macOS Keychain and the application's protected transport paths. Do not attach passwords, private keys, API tokens, VPN profiles, unredacted diagnostic logs or app-data backups to a public issue. Redact device/account identifiers from reports.

This preparation has no public issue tracker or security contact yet. Establish a private reporting channel when the owner creates the GitHub repository. Do not post security-sensitive details publicly in the meantime.

The public source is not a security audit or approval for unattended maintenance. GPU, network, recovery and deployment combinations require their own validation.
