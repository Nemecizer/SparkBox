# Contributing

Read AGENTS.md and docs/BUILDING.md. Use offline fixtures and the browser Demo first. Keep changes bounded, retain safeguard tests and explain how behavior was verified. Update applicable Help for user-visible changes.

Do not commit app state, credentials or real network captures. Use synthetic accounts and fixture addresses. Preserve third-party licenses. A public remote and contribution policy will be supplied by the owner when the repository is published; this preparation sends no pull requests or messages.
